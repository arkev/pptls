# PPTLS (Piedra, Papel, Tijera, Lagarto, Spock) 🖖

Un divertido videojuego web basado en el clásico juego extendido popularizado por Sheldon Cooper en la serie *The Big Bang Theory*.

## 🌐 Sitio Público y Código Fuente

**Nota Importante:** El código fuente completo de este proyecto se encuentra alojado en la rama **`gh-pages`** de este repositorio. 

Puedes visitar el sitio público y jugar la versión en vivo directamente en GitHub Pages a través del siguiente enlace:
👉 **[https://arkev.github.io/pptls/](https://arkev.github.io/pptls/)**

---

*Estás viendo la rama `master`. Por favor, asegúrate de cambiar a la rama `gh-pages` (`git checkout gh-pages`) para explorar los recursos, hojas de estilo (CSS) y scripts (JS) de la aplicación.*
